# Security policy

## Supported versions

Security fixes are applied to the latest released version of Forte.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose users
to malicious binaries or dependency compromise. Use GitHub's private
**Security → Report a vulnerability** workflow for this repository.

Include:

- the affected Forte and Binary Ninja versions;
- the operating system and Python version;
- a minimal reproducer when it is safe to share;
- the expected security impact.

Do not include credentials, private firmware, customer binaries, or personal
data. Maintainers will acknowledge a complete report as soon as practical and
coordinate disclosure after a fix is available.
